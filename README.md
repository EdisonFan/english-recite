# 初中英语课文跟读

一课一文件夹，三件套：**视频 + 封面 + 音频**。用于手机早读跟读，可直接传到抖音播放。

本仓库**不绑定某一个教材版本**。第一层目录是教材版本，各版本并列存放，后续新增版本直接作为兄弟目录加入，不需要改动已有结构。

## 目录结构

```
<教材版本>/                        ← 第一层：版本，可并列多个
└── <册次>/
    └── <单元>/
        └── <课次>/
            ├── 视频.mp4      1080×1920 竖版，逐句字幕，淡绿纯色护眼底
            ├── 音频.mp3      同一课纯音频，与视频时长一致
            └── 封面.png      1080×1920，「初中英语课文朗读 · 第 N 课」
```

已建立的册次分支：

```
冀教版/
├── 冀教版七年级英语上册(2024秋版)/
│   └── 第一单元 … 第六单元/          ← 6 单元 × 6 = 36 课
└── 冀教版七年级英语下册(2024年12月第1版)/
    └── 第一单元 … 第八单元/           ← 8 单元 × 6 = 48 课
```

以后加别的版本，例如：

```
人教版/
└── 人教版七年级英语上册(2024秋版)/
    └── 第一单元/
        └── 第一课/
外研版/
└── 外研版七年级英语上册(2024秋版)/
    └── ...
```

**四层固定：版本 → 册次 → 单元 → 课次。**

- 单元：`第一单元` … `第八单元`
- 课次：`第一课` … `第五课`；教材的 `Understanding cultures` 拓展板块单独叫 `单元拓展`，不硬编成「第六课」
- 课文件夹里只放三件套，不塞字幕、文稿或压缩包
- `.srt` 逐句字幕与纯英文文稿留在本地工作目录，按需取用

## 视频规格

- 1080×1920 竖版，H.264 + AAC，纯色淡绿底（无渐变）
- 微软神经语音，语速 −10%；对话课按角色切男女声，字幕标 ♂/♀ 与角色名
- 逐句字幕与真实语音对齐，每句后 0.75 秒跟读空白
- 画面文字按抖音播放实测收进安全区：左右各内缩 110px，底部上提留出平台 UI（黑边 147px → 缩放 1.1734 → 左右各裁 80 源像素）
- 其中 82 课音频来自必应翻译页朗读接口；七下 Unit 8 第三课与单元拓展两课因该接口触发限流，改由 `edge-tts` 合成，音色名与语速参数保持一致，并统一降采样、响度归一化后输出

## 上传节奏

**做完一课 → 生成一个文件夹 → 一次 commit**。一个课包对应仓库里一个目录，出问题只影响一课。

推送走 `api.github.com` 的 Git Data API（blobs → 带 `base_tree` 的 tree → commit → 更新 ref），一次原子提交且保留仓库已有文件。凭证只从环境变量 `GH_TOKEN` 读取，不写进脚本或文件。批量脚本带状态文件，中断后重跑自动跳过已完成课次。
