# 数据契约 · 三份 JSON 的字段定义与验收标准

以下字段名为**硬约定**，主流程按此读取，拼写不一致会被判为不合格并退回。

---

## 1. `课文数据.json`

```json
{
  "unit": 1,
  "unit_title": "Spring is coming!",
  "lessons": [
    {
      "no": "Lesson 1",
      "title": "Planting trees",
      "title_zh": "植树",
      "kind": "对话 · 刘老师与同学们讨论植树活动",
      "lines": [
        {"role": "MS LIU", "text": "Good morning, everyone! Who is on weather duty today?"},
        {"role": "WANG MEI", "text": "It's me! Today is Monday, March 1."}
      ]
    }
  ]
}
```

- `unit`：整数 1~8
- `lessons`：**恰好 6 个**，顺序为 Lesson 1~5、第 6 个为单元拓展
  （`no` 写 `"Unit cultures"` 或正文页上的实际标题）
- `kind`：中文简述体裁与场景，用于视频头部展示
- `lines[].role`：必须是任务书音色表里的值
- `lines[].text`：**教材原句**，超 170 字符已按句号切开

## 2. `教材基准.json`

```json
{
  "unit": 1,
  "lessons": [
    {
      "key": "U01_Lesson1",
      "no": "Lesson 1",
      "title": "Planting trees",
      "page": "教材 P2 / PDF p6",
      "kind": "与课文数据一致",
      "canonical": ["Good morning, everyone! Who is on weather duty today?", "..."],
      "source": "官方 PDF 正文页逐句整理（多栏按语义重排）",
      "inferred": ["逐条写清所有推断与待核对项"],
      "variants": []
    }
  ]
}
```

- `key` 规则：`U01_Lesson1` … `U01_Lesson5`、第 6 个用 `U01_CX`（单元号补零两位）
- **`canonical[]` 必须与 `课文数据.json` 的 `lines[].text` 逐条、逐字完全一致**
  这是最重要的一条，校验器直接比对这两个数组
- `page`：写教材页码与 PDF 页码，便于回溯
- `inferred`：不要省，写清剔除内容、断行合并、说话人推断、标题差异

## 3. `课文译文.json`

```json
{
  "unit": 1,
  "scope": "按子句逐句对应",
  "note": "中文译文按课文语境自译，课本原文无中文对照，仅供跟读理解参考",
  "items": [
    {"no": 1, "en": "Good morning, everyone!", "zh": "大家早上好！"},
    {"no": 2, "en": "Who is on weather duty today?", "zh": "今天谁值日报告天气？"}
  ]
}
```

- `items` 粒度是**子句**（把每条 `text` 再按 `. ! ?` 切开），不是朗读单元
- `no` 从 1 连续编到该单元子句总数
- `en` 与子句逐条对应，`zh` 为自译中文
- **译文不参与原文校验**，不冒充教材内容

---

## 验收闸门（主流程执行，其他 AI 不必自己跑）

| 检查 | 标准 |
|---|---|
| 结构 | 6 个板块齐全；`lines` 非空；`role` 合法；无中文混入英文 |
| 一致性 | `canonical` 与 `lines[].text` 相似度 **1.000** |
| 版本 | 官方 PDF 逐句命中率 **≥60%**，低于判「疑似版本不符」并阻断 |
| 拆句 | 最长句在竖版字幕折行 ≤ 12 行 |
| 译文 | 条数 = 子句数；`en` 与子句逐条对得上 |
| 清洁度 | 无练习题指令、表格字段、词表、页码残留 |

不合格时，主流程会在对应 `unitNN/` 放一份 `REJECT.md` 写清原因，
并把 `status.json` 置为 `rejected`；负责该单元的 AI 改自己的 3 个 JSON 后重新提交即可。
**通过之前不会进入语音合成，脏数据不会污染成片。**

---

## 后续流程（供了解，不需其他 AI 参与）

主流程拿到合格 JSON 后，依次做：拆句幂等校验 → 分声语音合成（微软神经语音，
语速 −10%）→ 音频静音检测得到真实句间停顿 → 分页锚定字幕渲染
（逐句点亮、页内零位移、横线上方译文条）→ 生成视频/音频/封面三件套 →
一课一个 commit 写入 `冀教版/冀教版八年级英语下册(2026春版)/`。
