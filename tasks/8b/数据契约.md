## 1. `课文数据.json`

```json
{
  "unit": 1,
  "unit_title": "Spring is coming!",
  "lessons": [
    {
      "no": "Lesson 1",
      "title": "Planting trees",
      "title_zh": "植树",
      "kind": "对话 · 刘老师与同学们讨论植树活动",
      "lines": [
        {"role": "MS LIU", "text": "Good morning, everyone! Who is on weather duty today?"},
        {"role": "WANG MEI", "text": "It's me! Today is Monday, March 1."}
      ]
    }
  ]
}
```

- `unit`：整数 1~8
- `lessons`：**恰好 6 个**，顺序为 Lesson 1~5、第 6 个为单元拓展
  （`no` 写 `"Unit cultures"` 或正文页上的实际标题）
- `kind`：中文简述体裁与场景，用于视频头部展示
- `lines[].role`：必须是任务书音色表里的值
- `lines[].text`：**教材原句**，超 170 字符已按句号切开（第 4 节有例外）

## 2. `教材基准.json`

```json
{
  "unit": 1,
  "lessons": [
    {
      "key": "U01_Lesson1",
      "no": "Lesson 1",
      "title": "Planting trees",
      "page": "教材 P2 / PDF p6",
      "kind": "与课文数据一致",
      "canonical": ["Good morning, everyone! Who is on weather duty today?", "..."],
      "source": "官方 PDF 正文页逐句整理（多栏按语义重排）",
      "inferred": ["逐条写清所有推断与待核对项"],
      "variants": []
    }
  ]
}
```

- `key` 规则：`U01_Lesson1` … `U01_Lesson5`、第 6 个用 `U01_CX`（单元号补零两位）
- **`canonical[]` 必须与 `课文数据.json` 的 `lines[].text` 逐条、逐字完全一致**
  这是最重要的一条，校验器直接比对这两个数组
- `page`：写教材页码与 PDF 页码，便于回溯
- `inferred`：不要省，写清剔除内容、断行合并、说话人推断、标题差异
  **以及第 5 节要求的 `allow_cjk` 声明**

## 3. `课文译文.json`

```json
{
  "unit": 1,
  "scope": "按子句逐句对应",
  "note": "中文译文按课文语境自译，课本原文无中文对照，仅供跟读理解参考",
  "items": [
    {"no": 1, "en": "Good morning, everyone!", "zh": "大家早上好！"},
    {"no": 2, "en": "Who is on weather duty today?", "zh": "今天谁值日报告天气？"}
  ]
}
```

- `items` 粒度是**子句**，按第 4 节那条正则切出来，**不是**朗读单元，也不是按语感自己断
- `no` 从 1 连续编到该单元子句总数
- `en` 与子句逐条**逐字**相等，`zh` 为自译中文
- **译文不参与原文校验**，不冒充教材内容
- `note` 必须声明自译 / 非教材原文

## 4. 子句切分：唯一口径（v2 新增，最重要）

`课文译文.json` 的 `items[].en` 必须**逐字等于**下面这条正则切出来的每一段。
这条正则来自渲染器 `_八上定稿_渲染.py`，译文表、验收闸门、自检脚本全部复用同一份，
**不允许任何一方自己实现一遍"按句号切"**。

```python
import re
SENT = re.compile(r'(?<=[.!?])\s+(?=[A-Z“"]I?)')

clauses = [s.strip() for line in lines
           for s in SENT.split(line["text"]) if s.strip()]
```

### 为什么必须写死

渲染器拿 `items` 做逐句点亮、分页锚定和横线上方译文条，
**条数与顺序差一条，后面全部整体错位**，而且画面不报错、只是「慢半拍」，最难查。
本轮 unit06 英文拼接起来与正文逐字一致，仅因切分口径不同（146 条 vs 144 条）被退回，
就是这条规则没写进契约的代价。

### 三个真实易错点（来自 unit06 退回单）

| 原文 | 正则结果 | 说明 |
|---|---|---|
| `Jules G. Verne takes us on…` | **切成 2 条**：`Jules G.` / `Verne takes us on…` | 缩写点后跟大写，会被切开。这是**期望行为**，不要好心合并 |
| `The Gift of the Magi by O. Henry.` | **切成 2 条** | 同上 |
| `“What are you doing here?” The giant got mad…` | **切成 2 条** | 引号后是空格 + 大写 `The`，切 |
| `Here it is. (He puts the packet of money on the table.)` | **不切，仍是 1 条** | 括号 `(` 不在 `[A-Z“"]` 里，舞台说明留在同一条 |
| `Could I show it to you?” The king handed…` | **切成 2 条** | 同引号例 |

一句话：**按正则切，不按语义切**。你觉得"这句话明明该连着"也要照切。

## 5. 豁免与提醒（v2 新增）

闸门分**硬错**（退回）和**豁免/提醒**（放行但记一笔），不再一刀切。

### 5.1 `allow_cjk` · 教材原文自带汉字

课本正文里偶尔直接出现汉字，是**教材内容**，不算「英文混入中文」：

| 册 | 例子 | 语境 |
|---|---|---|
| 八上 U4 | `鱼(fish)` | 讲象形字 |
| 八下 unit07 | `Think of the Chinese character “贩”.` | 讲汉字字形 |

放行条件（两条都要）：

1. 该课 `教材基准.json` 的 `inferred` 里写明「教材原字 / 汉字 / allow_cjk」并写出那个字
2. 汉字只出现在该处正文，不出现在练习题、词表、页眉页脚里

主流程入库渲染时登记 `allow_cjk` 白名单，字幕正常显示，译文条照常对齐。

### 5.2 练习题指令只匹配「指令」，不匹配正文动词

正则只拦 `Listen and tick` / `Listen to the conversation` / `Read the passage and…`
这类**祈使指令**。正文里 `They loved to listen to the singing of the birds.`
是叙述句里的普通动词短语，**不得判为练习题残留**。
（本轮 unit06 初检误报过一次，已在闸门与自检里同步修掉。）

同理，`A driver stopped…` 句首冠词 `A` 不等于选项 `A`，不要当选项剔除。

### 5.3 超 170 字符长句：先问"还能不能切"

| 情况 | 判定 |
|---|---|
| >170 字符，且 `SENT.split()` 还能切出 2 段以上 | **硬错**：按句号切开 |
| >170 字符，但整句**只有一个句末标点**，切不动 | **提醒，不阻断**；改用渲染器 `wrap()` 实测折行，≤12 行即放行 |

折行用渲染器同款算法（54 px 字号、`SW-70` 宽、按词换行）。
实例：unit07 第 6 课 215 字符那句，切不动、实测折 **6 行**，放行。

## 验收闸门（主流程执行；分包 AI 用自检脚本提前跑同一套）

| 检查 | 标准 | 类型 |
|---|---|---|
| 结构 | 6 个板块齐全；`lines` 非空；`role` 合法 | 硬错 |
| 中文混入 | 无中文；**教材原字按 5.1 豁免** | 硬错 / 豁免 |
| 一致性 | `canonical` 与 `lines[].text` **逐字**一致 | 硬错 |
| 版本 | 官方 PDF 逐句命中 **≥60%**、词覆盖 ≥0.95 | 硬错 |
| 红线 | 无旧版教材特征 | 硬错 |
| 拆句 | 按 5.3：能切必须切；切不动则折行 ≤12 行 | 硬错 / 提醒 |
| 译文 | 条数 = **第 4 节正则**切出的子句数；`en` 逐条逐字相等；`no` 连续 | 硬错 |
| 清洁度 | 无练习题指令（按 5.2）、表格字段、词表、页码残留 | 硬错 |

不合格时，主流程在对应 `unitNN/` 放 `REJECT.md` 写清原因与**完整期望清单**，
`status.json` 置 `rejected`；只改自己那 3 个 JSON 重交即可，不影响其他单元。
**通过之前不进语音合成，脏数据不会污染成片。**
