# 阶段⑥ · 视频渲染分包任务包（本次只开放 unit01）

> 你只做一件事：**把已验收的音频 + 时间轴 + 译文，渲染成 6 个课包**。
> 不整理课文、不合成语音、不上传成片、不碰别人的单元。
> 渲染器、字体、输入数据全部备好，**一条命令跑完，不要改任何代码**。

---

## 0. 为什么这件事分出来

音频合成 2 分钟能跑完全册，视频渲染一课要 1～1.7 分钟（1080×1920 逐帧压字幕），
全册 48 课约 1 小时。**你的机器若比主流程快，这一步最值得并行**。
本次先只做 **unit01 六课**，跑通再谈其余单元。

## 1. 环境（先确认，不满足就别开跑）

| 项 | 要求 |
|---|---|
| Python | ≥ 3.9 |
| Python 包 | `Pillow>=9.0`（`pip install -r tasks/8b/video/requirements.txt`） |
| ffmpeg / ffprobe | 必须带 **libass**（ASS 字幕）、**libx264**、**aac** |
| 字体 | **不用装**，仓库 `tasks/8b/video/fonts/` 已自带 3 个字体 |

一键查环境：

```
python tasks/8b/video/自检.py unit01
```

它先跑环境检查，缺什么会直接列出来。常见坑：某些精简版 ffmpeg 没编 libass，
字幕会整个不显示但**不报错**，所以这一步别跳。

---

## 2. 输入：全部已在仓库，不用你准备

| 路径 | 内容 |
|---|---|
| `tasks/8b/video/渲染_unit01.py` | 主流程同一份渲染实现，**原样运行，不要改** |
| `tasks/8b/video/data_unit01.json` | 预生成：6 课元信息 + 逐课子句/译文（已逐条校验） |
| `tasks/8b/video/fonts/` | 3 个字体文件，随包走，不依赖系统 |
| `results/8b/unit01/audio/` | 已验收的 6× MP3 + 6× timeline.json（**只读**） |

`data_unit01.json` 里每课的 `en` 是按唯一口径
`SENT = re.compile(r'(?<=[.!?])\s+(?=[A-Z“"]I?)')` 切出的子句，
`zh` 是逐条对应的中文。渲染器会 assert 两者与音频切出的子句流逐字相等，
对不上会直接退出，**不要去改 data 让它"过"**。

## 3. 怎么做（就一条命令）

在**仓库根目录**：

```
pip install -r tasks/8b/video/requirements.txt
python tasks/8b/video/渲染_unit01.py
python tasks/8b/video/自检.py unit01
```

想先试一课再跑全套：

```
python tasks/8b/video/渲染_unit01.py --only U01_Lesson1
```

预计 **8～12 分钟**（6 课 × 1～1.7 分钟，2 核 CPU 实测）。中途断了直接重跑，
脚本按课覆盖输出，不会留半成品。

## 4. 输出契约（写错目录等于白干）

只写 `results/8b/unit01/video/`，**恰好 6 个子目录 × 3 个文件 = 18 个文件**：

```
results/8b/unit01/video/U01_Lesson1/视频.mp4
                               /音频.mp3
                               /封面.png
results/8b/unit01/video/U01_Lesson2/视频.mp4   音频.mp3   封面.png
...
results/8b/unit01/video/U01_Lesson5/视频.mp4   音频.mp3   封面.png
results/8b/unit01/video/U01_CX/视频.mp4        音频.mp3   封面.png
```

硬规则：

| 文件 | 标准 |
|---|---|
| `视频.mp4` | 1080×1920、24fps、H.264 + AAC、时长 ≈ `timeline.total`（±1s）、全帧解码 0 错误 |
| `音频.mp3` | **原样复制** `results/8b/unit01/audio/` 里对应那份，sha256 必须一致，不得重编码 |
| `封面.png` | 1080×1920 PNG，竖版淡绿护眼底，主流程同款 |

渲染器已内置：分页锚定、页内零位移、逐句点亮、蓝竖条贴齐墨迹、
横线上方译文条、头部⑤版、ASS 译文事件数 = 子句数、全帧解码核验。
**这些版式参数一个字都不要改**，否则跟已交付的八上 48 课对不上。

产物约 **35～45 MB**，push 可能慢一点，耐心等。
