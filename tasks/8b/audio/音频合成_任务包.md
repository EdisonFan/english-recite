## 1. 用什么（一个字都别改）

| 项 | 值 |
|---|---|
| 引擎 | 微软 Edge TTS 神经语音（`edge-tts` Python 包，非 Azure 订阅版） |
| 版本 | `edge-tts==7.3.1`，Python ≥ 3.9 |
| 语速 | **`rate='-10%'`** |
| 采样 | 16000 Hz、单声道、16-bit PCM 中间文件 |
| 句间静音 | **每条朗读单元后插入 0.75 秒静音** |
| 响度 | `loudnorm=I=-17:TP=-1.5:LRA=11`（失败则跳过归一化） |
| MP3 编码 | `libmp3lame -q:a 2` |
| 失败重试 | 每句 4 次，间隔 2/4/6 秒 |

**音色按 `data_unitNN.json` 里每行的 `voice` 字段走，不要自己挑、不要按 role 猜。**
本册 8 个单元只用到 5 种声音，全表在 `音色表.json`：

| role | voice |
|---|---|
| NARRATOR / WANG MEI | `en-US-AriaNeural` |
| JENNY / LI LIN | `en-US-JennyNeural` |
| LI MING | `en-US-GuyNeural` |
| BRIAN / DANNY / SONG HUA | `en-GB-RyanNeural` |
| MS LIU | `en-GB-SoniaNeural` |

## 4. 输出契约（最重要，错一条我方渲染就废）

### 4.1 目录

只写 **`results/8b/unitNN/audio/`**，恰好 6×2 = 12 个文件：

```
U01_Lesson1.mp3            U01_Lesson1.timeline.json
U01_Lesson2.mp3            U01_Lesson2.timeline.json
...
U01_Lesson5.mp3            U01_Lesson5.timeline.json
U01_CX.mp3                 U01_CX.timeline.json
```

不要放 `report.json`、`worker.log`、脚本、说明文字。

### 4.2 `*.timeline.json`

顶层 7 个字段，缺一不可：

```json
{
  "key": "U01_Lesson1",
  "no": "Lesson 1", "title": "Planting trees",
  "title_zh": "植树", "kind": "对话 · ...",
  "timeline": [
    {"start": 0.0, "end": 11.718,
     "role": "MS LIU", "text": "Good morning, everyone! ..."}
  ],
  "total": 93.132
}
```

硬规则：

- `timeline` 条数 = 该课 `data_unitNN.json` 的 `lines` 条数
- 每条 `text`、`role` 与对应 `lines[]` **逐字一致**（弯引号 `’` 不许改成 `'`）
- `start[0] == 0`；`start[i] == end[i-1]`；`end[i] > start[i]`
- **`end[i] = start[i] + 该句音频时长 + 0.75`**（句间静音必须真的拼进 MP3）
- `total == timeline[-1].end`，且 ≈ MP3 时长（容差 1 秒）

> ⚠️ **0.75 是硬契约，不是建议。** 我方渲染器用
> `朗读时长 = (end - start) - 0.75` 反推每句真实发声长度，再据此做逐句点亮、
> 分页锚定和静音检测。你少插一秒、多插半秒，整课字幕会全程错位，
> 而且这种错在画面上不炸、只是「慢半拍」，最难查。

### 4.3 MP3

- 单声道 16 kHz，可解码、有音频流
- 每课时长 > 20 秒、文件 > 100 KB
- 中间失败重试 4 次后仍失败，就**整单元不要交**，回复说明哪句失败
